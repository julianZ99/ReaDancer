# Example character packs

Self-made packs for testing ReaDancer. Every cell is labelled `row,frame` and
colour-coded per row, so you can see exactly which cell the renderer is drawing.

- **Classic8** — a plain Fruity Dance pack: 8 columns, 3 rows (`Idle`, `Wave`,
  `Held`), no header. Exercises the classic parse path.
- **Groovy12** — an extended pack (`#readancer 1`): 12 columns, `#beats 2`, with
  per-move frame counts. `Wave` uses only 6 of the 12 frames and `Held` only 1 —
  the unused cells are greyed out in the sheet.

Load either `.png` from ReaDancer's **Load…** button; the sibling `.txt` is
picked up automatically.

These are generated by `scripts/gen_examples.py` (ImageMagick + Python), not
hand-drawn — regenerate with that script if you change the format.
